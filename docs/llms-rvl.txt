# Rapise Visual Language (RVL)

RVL is a spreadsheet-based test scripting language. Tests are written in Excel files (`.rvl.xlsx`) with a structured 7-column format.

## RVL Structure

Every RVL script has exactly 7 columns:

| Flow | Type | Object | Action | ParamName | ParamType | ParamValue |
|------|------|--------|--------|-----------|-----------|------------|

- **Flow**: Control flow keywords (If, ElseIf, Else, Loop, End, Map, #, /*, */, ?, And, Or)
- **Type**: Row type (Action, Variable, Param, Condition, Assert, Rows, Range, Database)
- **Object**: Object ID or map name
- **Action**: Method to call or condition type
- **ParamName**: Parameter name
- **ParamType**: Data type (string, number, boolean, variable, expression)
- **ParamValue**: Parameter value

## Actions

Call an object method. Every action stores its return value in the built-in `LastResult` variable, which can be used by the next action.

| Flow | Type | Object | Action | ParamName | ParamType | ParamValue |
|------|------|--------|--------|-----------|-----------|------------|
| | Action | LoginButton | DoClick | | | |

Action with parameters:

| Flow | Type | Object | Action | ParamName | ParamType | ParamValue |
|------|------|--------|--------|-----------|-----------|------------|
| | Action | UsernameField | DoSetText | txt | string | admin |

Action with multiple parameters (additional params on Param rows):

| Flow | Type | Object | Action | ParamName | ParamType | ParamValue |
|------|------|--------|--------|-----------|-----------|------------|
| | Action | Global | DoLaunch | cmdLine | string | notepad.exe |
| | Param | | | wrkDir | string | C:\Temp |

Using LastResult from previous action:

| Flow | Type | Object | Action | ParamName | ParamType | ParamValue |
|------|------|--------|--------|-----------|-----------|------------|
| | Action | MyField | GetText | | | |
| | Action | Tester | Message | message | variable | LastResult |

### Conditional Action

`?` in Flow column - action only runs if object exists:

| Flow | Type | Object | Action | ParamName | ParamType | ParamValue |
|------|------|--------|--------|-----------|-----------|------------|
| ? | Action | OptionalPopup | DoClick | | | |

### If-ElseIf

| Flow | Type | Object | Action | ParamName | ParamType | ParamValue |
|------|------|--------|--------|-----------|-----------|------------|
| If | Param | | | param1 | variable | mode |
| | Condition | | param1 == param2 | | | |

| # | Create mode | | | | | |

| | Condition | | param1 == param2 | | | |
| | Param | | | param2 | string | edit |
| # | Edit mode | | | | | |
| End | of ElseIf | | | | | |

### Condition Operators

**Binary conditions:**
- `param1 == param2` - equals
- `param1 != param2` - not equals
- `param1 > param2` - greater than
- `param1 >= param2` - greater or equal
- `param1 < param2` - less than
- `param1 <= param2` - less or equal
- `param1 contains param2` - substring check

**Unary conditions:**
- `param1 IsTrue` - checks if true
- `param1 IsFalse` - checks if false
- `param1 IsNull` - checks if null
- `param1 IsNotNull` - checks if not null
- `param1 IsSet` - checks if has a value (not null/empty/0/false)
- `param1 IsNotSet` - checks if empty/null/0/false

### And/Or Conditions

| Flow | Type | Object | Action | ParamName | ParamType | ParamValue |
|------|------|--------|--------|-----------|-----------|------------|
| If | Param | | | param1 | variable | a |
| | Condition | | param1 > param2 | | | |
| | Param | | | param2 | number | 0 |
| And | Param | | | param1 | variable | b |
| | Condition | | param1 < param2 | | | |
| | Param | | | param2 | number | 100 |
| # | Both conditions true | | | | | |
| End | of If | | | | | |

## Calling JavaScript Functions

Define functions in `User.js`, call them from RVL via `Functions` object:

```javascript
// In User.js
function CalculateTotal(price, qty) {
    return price * qty;
}
```

| Flow | Type | Object | Action | ParamName | ParamType | ParamValue |
|------|------|--------|--------|-----------|-----------|------------|
| | Action | Functions | CalculateTotal | price | number | 10 |
| | Param | | | qty | number | 5 |

Result is stored in `LastResult` variable.

## RVL-JavaScript Interop

### Running RVL from JavaScript

```javascript
// In Main.js
function Test(params)
{
    RVL.DoPlayScript("Main.rvl.xlsx");
}

// Run specific sheet
RVL.DoPlayScript("Main.rvl.xlsx", "LoginSheet");
```

### Passing Parameters

```javascript
// Pass params to RVL
RVL.DoPlayScript("Main.rvl.xlsx", "TestSheet", {
    username: "admin",
    environment: "staging"
});
```

Access in RVL using Global variables.
